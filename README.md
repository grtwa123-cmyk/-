# Science Experiments

A small hub of interactive physics experiments built with vanilla HTML, CSS,
and JavaScript. No build step, no dependencies — just open
[`index.html`](./index.html) in a browser.

## Experiments

- **Projectile Motion** — adjust launch velocity, angle, and gravity; live
  readouts for range, max height, time of flight, and the current state of
  the projectile.
- Pendulum, Gravity & Orbits, Wave Interference — placeholders for future
  experiments.

## Layout

```
index.html              # Hub landing page
styles.css              # Shared styles
experiments/
  projectile.html       # Projectile motion experiment
  projectile.js         # Physics + canvas animation
```
