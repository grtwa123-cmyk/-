Build an Atom

Drag protons, neutrons, and electrons onto the atom. The number of protons alone decides which element you have; electrons set the overall charge; neutrons change only the mass and nuclear stability. Drag a particle back to its bucket to remove it.

Formulas
  • Element: Z = number of protons
  • Net charge: q = protons − electrons
  • Mass number: A = protons + neutrons
  • Isotope: same Z, different N
Notes
  • Protons alone define the element — one proton is hydrogen, six is carbon. Add or remove a proton and you have a different element entirely.
  • Electrons carry the charge. Equal protons and electrons → neutral; fewer electrons → a positive ion (cation); more → a negative ion (anion).
  • Neutrons change neither the element nor the charge — only the mass number and whether the nucleus is stable. Same element, different neutron count = isotopes.
